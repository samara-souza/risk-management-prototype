# Risk Management System

Protótipo de um sistema para gerenciamento e acompanhamento de riscos, desenvolvido durante o **7º período do curso de Engenharia de Software**, na disciplina de **Jornada de Aprendizagem**.

O projeto foi desenvolvido em equipe como resposta a um desafio proposto por uma empresa parceira da universidade, tendo como objetivo criar uma interface intuitiva para o cadastro, acompanhamento e gerenciamento de riscos.

---

## Objetivo

Desenvolver um protótipo navegável que permitisse visualizar informações relacionadas aos riscos identificados, facilitando seu monitoramento e definição de planos de resposta.

---

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Figma (protótipo e design)

---

## Funcionalidades

- Login de usuários
- Dashboard com visão geral
- Listagem de riscos
- Cadastro de novos riscos
- Visualização dos detalhes de um risco
- Plano de resposta
- Página de ajuda

## Como executar

Como este projeto é um protótipo front-end, basta:

1. Clonar o repositório

```bash
git clone https://github.com/seu-usuario/risk-management-system.git
```

2. Abrir o arquivo

```
pages/login.html
```

em qualquer navegador moderno.

---

## Fluxo da aplicação

O usuário pode:

1. Realizar login;
2. Visualizar o dashboard;
3. Consultar a lista de riscos;
4. Visualizar detalhes de um risco;
5. Cadastrar novos riscos;
6. Definir um plano de resposta.

## Limitações

Este projeto representa um **protótipo funcional de interface**, desenvolvido para demonstrar o fluxo da aplicação.

Não possui integração com banco de dados ou backend, utilizando dados simulados para representar o comportamento esperado do sistema.
